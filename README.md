## 1. サービス概要
- このサービスはどんなサービスか
超寄り添い、超戦う習慣化アプリ。
個性豊かなシュカモンから励ましを受けながら、楽しんで継続できる。
習慣を続けることでキャラクター「シュカモン」が成長し、育てたシュカモンでカードバトルを楽しめる。

- 誰の、どんな課題を、どう解決するか
勉強や運動などを継続しているものの、成果がすぐには見えず成長を実感しにくい人や、一人で努力を続けることに孤独を感じる人を対象として、習慣の継続によるユーザーの成長をバトルの強さとして可視化する。
さらに各シュカモンの経験や価値観に基づいた励ましを届けることで、継続する楽しさを提供する。


## 2. アイデアを作る上で私が発揮した個性

### 2-1. 心理学に興味がある
心理学の概念である外発的動機づけを利用して、アプリ内のコンテンツ同士で需要を生み出し合えるようにした。

- 【バトル ← 習慣】バトルで勝ちたいので、毎日タスクをこなす
- 【報酬 ← バトル】習慣化テクニックを読みたいので、バトルでレートを集める
- 【習慣 ← 報酬】習慣をより有意義に続けやすくするコツを知りたいので、報酬の習慣化テクニックを読む


### 2-2. ドット絵を見るのも描くのも好き
シュカモン（アプリ内のキャラクター）はすべてドット絵で自作した。


### 2-3. ゲームが好き
デッキ構築のようなプレイヤーの個性が出るゲームや、コツコツレベルを上げていくゲームが好き。


### 2-4. 習慣をいくつか持っている
プログラミングとランニングを毎日続けている。
どちらも、いきなり目に見えて上達を実感できるようなものではないため、成長を実感しやすい習慣化アプリが欲しいと思っている。



## 3. このアイデアはどこから生まれたか

### 3-1. きっかけとなった体験・感情
きっかけは2つある。

- 習慣をするとゲームが進まず、ゲームをすると勉強が進まないというジレンマを抱えていた
習慣も、ゲームのレベル上げも、同じ"努力"であるはずなのに、どちらかを進めればもう一方は停滞してしまう。これは少しもったいないのではないかと感じた。
プログラミングやランニングをするたびに、ゲームのキャラクターに経験値が溜まっていけば良いのになぁと思ったため、習慣化によりシュカモンを強化してバトルに挑む継続王の作成を決断した。


- 超真面目な友達が、夜更かししてゲームをしていた
仕事では毎月100時間の残業をし、通信制大学に通い、英語の勉強もしている友人のK君がいる。
K君はとても真面目なので、高校の時に大好きだったゲームへの興味を無くして、淡々とやるべきことをこなしているのだと勝手に思い込んでいた。
しかし、K君と一緒に旅行をした際に、その思い込みは打ち砕かれた。「何度も、睡眠時間を削ってシャドウバース（オンラインゲーム）をプレイして、次の日の仕事で地獄のような思いをしている」という愚痴を聞いたからだ。
この経験から、真面目な人間も実は自分と同じく遊びたい欲求をもっており、それを頑張って抑えながら努力しているのではないか？という仮説が立った。そうであるならば、娯楽と努力を両立できる手段がもしあれば、真面目な人間にとっても嬉しいはずである。継続王は自分のためだけでなく、K君のような人の役にも立てるアプリになるのではないかと思い、より作成意欲が高まった。



### 3-2. なぜそれが「気になった」のか
現実の努力は、ゲームの経験値のように成長が可視化されないし、目に見えた変化はすぐには起きない。
ランテック入学後はプログラミングでこのことを強く実感し、継続して努力することの難しさを改めて学んだ。
既存の習慣化アプリを使ったり、AIに毎日報告して励ましてもらったりしたこともあるが、継続日数の数字だけが上がっていく様はどこか機械的で、励ましの言葉には血が通っていないような感覚がした。

だからこそ、強くなったことを実感したい。血の通った励ましを受けたいと思った。

その経験を活かし、継続王では現実で継続するほど「バトルの強さ」として成長のフィードバックを受けられるようにした。
また、シュカモンから、人間味があって各キャラクターの背景に合った激励や称賛を受けられるようにして、孤独な挑戦を支えられるようにした。


## 4. 課題の整理（表面的になっていないか）
### 4-1. 表に見えている困りごと
1. 現実の努力は、ゲームの経験値のように成長が可視化されず、目に見えた変化はすぐには起きない。
2. 習慣化は血の通った励ましを受けづらい。

### 4-2. 本当に解決したい課題は何か

1. 成長が可視化されず、目に見えた変化はすぐには起きない。

    - なぜ、成長が可視化されず、目に見えた変化はすぐには起きないのか？
        → 現実世界の成長は、ゲームのレベルのように比例的に成長していくわけではない。

    - なぜ、現実世界の成長は、ゲームのレベルのように比例的に成長していくわけではないのか？
        → 現実の成長は、努力した直後に必ず成果として現れるわけではなく、停滞や失敗を挟みながら後から成果が現れることもあるため。

    - なぜ、現実の成長は努力した直後に必ず成果として現れるわけではないのか
        → 現実の成長には停滞や失敗が伴う一方、ゲームではプレイヤーが成長を実感しやすいよう、経験値やレベルによって成長が分かりやすく表現されている。

    - なぜ、ゲームの世界は比例的で失敗の少ない不自然な成長を採用したのか
        → 成長を実感できると楽しいから。

    これにより、ゲームの世界の成長は、プレイヤーが楽しめるように人為的に作られており、これを現実世界の成長とリンクさせることで、現実世界の成長も実感しやすくなるという仮説が導かれる。


2. 習慣化は血の通った励ましを受けづらい。

    - なぜ、習慣化は血の通った励ましを受けづらいのか？
        → 周りに同じ状況の人が少ないから。

    - なぜ、周りに同じ状況の人が少ないのか？
        → 人には多様性があり、目標は人によって異なるから。

    - なぜ、人には多様性があり、目標は人によって異なるのか？
        → それぞれが異なる経験や価値観を持っているから。

    これにより、家族や友達がいても習慣化において孤独を感じる理由は「それぞれが異なる経験や価値観を持っているから」であるとわかった。
    ここから、自分と近い経験や価値観を持つキャラクターから励ましを受ければ、孤独感も薄れることが予想できる。
    継続王では、登場するキャラクターは、キャラクター自身の経験から作られた自然なセリフでプレイヤーを励ましてくれるようにした。

    例：
        かぐや姫：
            異境の地「地球」で生活した経験から、新しい挑戦を始め、新天地で頑張るプレーヤーにとって共感できるキャラクターとした

        ニコラ・テスラ：
            習慣をやり忘れた際には、タスクを減らすよう促す。これは、テスラがエジソンの試行錯誤中心の実験方法を批判した逸話をモチーフとしている。

→ 本当に解決したい課題：成長を実感したい、同じ境遇や考えの人から励まされたい。

しかし、効果音のない戦闘は手応えに欠ける可能性があり、ユーザーの意見を聞きつつ、効果音やBGMの追加を検討しようと考えている（将来的に追加する場合も、初期設定ではOFFとする）

### 11-3. 開発前に抱いていた懸念

1. **完成までのハードルが高い**
開発開始時点ではJavaScriptをほとんど扱った経験がなく、カードの移動・攻撃・ダメージ表示など、多数のアニメーションを伴うバトル画面を完成させられるか懸念していた。
実際にバトル画面の実装には多くの時間を要した。特に、戦闘ロジックと複数のアニメーションを連動させることや、PCとスマートフォンの異なる画面サイズで同じ戦闘を成立させるレスポンシブ対応に苦戦した。
AIによるコード生成だけに頼らず、実際のカードゲームのモーションを録画して観察したり、生成されたコードの動作を確認しながら修正を繰り返したことで、最終的にバトル画面を完成させることができた。
2. **Issueの見積もりが難しい**
JavaScriptの経験がほとんどなかったため、開発前は各機能の実装時間を正確に見積もることが難しかった。実際に、バトル機能やスマートフォンへのレスポンシブ対応は当初の想定以上に時間がかかった。
そのため、初回リリースに必要な機能の優先順位を見直し、最終撃破演出など、サービスの主要な価値に直接影響しない演出は初回リリース後の実装へ回した。すべてを予定どおり実装するのではなく、リリースに必要な機能を優先して開発範囲を調整した。
